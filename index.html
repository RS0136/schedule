    使い方・保存について

    予定を入れる

    「予定を追加」で名前・開始・終了・色を選びます。棒の区画、または下の予定一覧からも編集できます。時間を入れると、自動で棒が区切られます。

    棒に仕切りを入れる

    「仕切りを入れる」に切り替え、棒をタップします。同じ予定を引き継いだ2つの区画に分かれます。区切ったら「予定を編集」に戻し、それぞれに名前を付けてください。

    時間を調整する

    仕切りのつまみをドラッグします。つまみをタップすると時刻を直接入力でき、仕切りの削除もできます。ドラッグは選んだ刻み、手入力は1分単位です。キーボードでは仕切りにフォーカスして矢印キー、Shift + 矢印で1分、Enterで入力画面を開けます。

    棒の長さ・太さを変える

    「棒のサイズ」のスライダー、またはpxの数値を変更します。長さは120〜10,000px、太さは8〜1,200pxで、数値は1px単位です。横向きでは長さが横幅、太さが高さ。縦向きでは長さが高さ、太さが横幅です。予定の時刻や時間配分は変わりません。

    サイズは横向き・縦向きで別々に自動保存します。「幅を画面に合わせる」で画面幅に追従する設定にし、「標準に戻す」で今の向きのサイズだけを初期値に戻せます。大きい棒はスクロールで確認してください。細い棒では文字を省略し、下の一覧や区画の編集画面で名前を確認できます。PNGにも棒の向きとサイズを反映しますが、非常に大きい画像は保存時に全体を縮小します。

    保存とバックアップ

    日付ごとに、この端末・このブラウザの localStorage に保存します。アカウント登録・外部ライブラリ・予定の送信処理はありません。別の端末との自動同期はしません。「…」から全日分をJSONに書き出し、別のブラウザに読み込めます。

    ブラウザのデータ削除やプライベートモードでは予定が失われる場合があります。大切な予定はバックアップしてください。元に戻す履歴は再読み込みすると消えます。

    日をまたぐ予定

    この棒は00:00〜24:00の1日分です。23:00〜翌07:00は、この日の23:00〜24:00と、翌日の00:00〜07:00に分けて入力してください。日付と現在時刻は端末のタイムゾーンを使います。

    公開するもの・しないもの

    GitHub Pagesで公開するのは、このアプリのファイルです。アプリ内で入力した予定はコードには書き込まれません。バックアップJSONや予定の画像を、公開リポジトリにアップロードしないでください。共有端末では、他の利用者が保存済み予定を見られます。
